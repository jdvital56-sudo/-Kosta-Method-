## Структура репозитория

```
README.md            — описание проекта
PLAN.md              — план работ и статус (этот файл)
PROGRESS.md          — текущий прогресс по шагам
CHANGELOG.md         — история изменений
App.tsx, index.ts    — точка входа Expo-приложения
src/theme/           — дизайн-система (цвета, типографика)
src/types/           — доменные типы
src/constants/       — каталог программ, шаблоны тренировок
src/store/           — Zustand-сторы
src/services/        — API-клиент, auth, workouts, aiCoach
src/navigation/      — RootStack + BottomTabs
src/screens/         — экраны приложения
src/components/      — переиспользуемые компоненты
backend/             — NestJS-сервер (auth, users, workouts, ai, progress, payments)
docs/                — документация (api-contract)
.github/workflows/   — CI
sessions/            — журнал рабочих сессий
```

## Принципы синхронизации

- Все документы, план и существенные обновления сессии фиксируются здесь.
- Системные конфигурации, ключи и credentials не публикуются.
- Каждое обновление — отдельный коммит с понятным сообщением.

## Дорожная карта (roadmap)

1. **Этап 1 (текущий)** — MVP фронтенда + каталог программ + каркас backend ✅ код написан
2. **Этап 2** — персонализация: замеры, фото-прогресс, экран настроек цели
3. **Этап 3** — подписки: RevenueCat (клиент + webhook), paywall-эксперименты
4. **Этап 4** — backend production: PostgreSQL, JWT-guard, миграции, деплой
5. **Этап 5** — AI-Костя с контекстом плана и историей, голосовые подсказки
6. **Этап 6** — QA, тесты, EAS-сборки TestFlight / Google Play beta
